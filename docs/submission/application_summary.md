## 개요 및 주요 기능(핵심 요약)

KS-Fix는 한국산업표준(KS) 표준안(docx)을 KS A 0001:2023(표준의 서식과 작성방법)에 맞춰 자동으로 점검·교정하는 AI 도구입니다.
① 머리말·적용범위·인용표준·용어와 정의·부속서 등 문서 구조를 인식하고, ② KS A 0001 조항 근거가 있는 규칙 47종(신뢰성 규칙 3종 별도)으로 위반을 찾으며, ③ 정형문·표와 그림 제목·단위 띄어쓰기·연속부호·허용오차 표기처럼 확정 가능한 항목은 Word 변경추적으로 자동 수정하고, ④ 요구·권고·허용 표현처럼 판단이 필요한 문장은 AI가 근거와 함께 제안합니다. ⑤ 부속서 A 검토 항목 53개 체크리스트와 수정 전후 리포트를 만들고, ⑥ 수치·표준번호 같은 기술적 내용은 바뀌지 않았음을 자동 검증합니다.

## 성과 지표(합성 데이터·로컬 검증)

| 지표 | 결과 |
|---|---|
| 합성 위반본(위반 52건 주입) | 결정형 규칙 기대 지적 재현율 49/49(100 %), 자동수정 25건, 규칙 통과율 0 % → 51 %, 처리 약 0.6초 |
| 합성 정상본 | 오류·경고 0건(오탐 없음) |
| 구조 인식 | 합성 표준안 3종 문단 역할 정확도 100 % |
| 발간 KS 문서 2종(로컬, 외부 전송 없음) | 문서당 1~4초, 실제 위반(목차 미갱신·이전 판 정형문·단위 표기 등) 검출, 규칙 통과율 83~87 % → 89 % |
| 기술적 내용 불변 | 모든 출력에서 수치·단위·표준번호·표 값 비교 검증 통과(실패 시 자동 철회) |
| LLM 모델 비교(합성 60문장, CPU) | EXAONE 3.5 7.8B 유형 정확도 75 %·허용 판별 97 %·문장당 24.5초 / Gemma 3 4B 82 %·97 %·9.4초 |

## 기대 효과

- 표준안 서식 검토 시간을 줄이고, 담당자는 변경추적에서 수락·거절만 결정
- 검토 기준(KS A 0001 조항)이 지적마다 명시되어 검토 품질의 편차 감소
- 규칙팩 구조라 단체표준·기관 문서표준 등 다른 서식 기준으로 확장 가능
- LLM 없이도 동작하고 로컬 처리라 업무망·폐쇄망에 적용하기 쉬움
